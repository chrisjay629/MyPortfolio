# Christopher Jauregui — Portfolio

Personal site for Christopher Jauregui — operations leader, entrepreneur, and AI-native product builder based in Austin, TX.

**Live:** https://chrisjay629.github.io/MyPortfolio/

## Stack
Hand-built static site — no framework, no build step.
- `index.html` — single-page site
- `css/site.css` — styles (warm-dark theme, Fraunces / Inter / JetBrains Mono)
- `js/site.js` — light vanilla-JS interactions (scroll reveal, sticky nav)
- `decks/` — self-hosted product pitch decks
- `CHRISTOPHER_L_JAUREGUI2.pdf` — résumé

## Local preview

python3 -m http.server 8000
# open http://localhost:8000
